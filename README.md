# StatBall

A web app for comparing Premier League players and teams side by side, built as my OCR A-level Computer Science coursework (70/70 after moderation).

![Screenshot of the comparison page](screenshots/compare.png)

## What it does
- Compare stats for 600+ Premier League players, [and teams]
- Charts built with Chart.js so you can see the differences at a glance
- [One more feature you're proud of]

## How it works
1. A Python scraper collects player data and images
2. The data is cleaned into CSV files
3. A Flask backend serves it to a JavaScript front end, where Chart.js draws the visualisations

## Tech
Python, Flask, HTML, CSS, JavaScript, Chart.js
